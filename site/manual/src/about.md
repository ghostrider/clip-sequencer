# About this manual

This manual describes **Clip Sequencer for Resolume** in the version shown at the bottom of each page. It is
published with each release. For the changes in each version see the
[changelog](https://github.com/ghostrider/clip-sequencer/blob/main/CHANGELOG.md); older versions are on the
[releases page](https://github.com/ghostrider/clip-sequencer/releases).
