Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: applied for. Releases up to and including 0.2.0 are not signed; this page says from which version on they are once signing is set up.

What is signed

The Windows programs in the release zip clip-sequencer-<version>-windows-x64.zip on GitHub Releases, all in its folder clip-sequencer:

  • seq-app.exe, the desktop app
  • seq-app-cli.exe, the console program
  • ffgl/SeqView.dll, the "1000A Sequence" FFGL plugin for Resolume

Only files built from this project's own source code are signed. Third-party libraries are compiled into these files and listed with their licenses in THIRD_PARTY_LICENSES.md in the zip and under Help → Licenses in the app; no third-party program is signed on its own.

How releases are built

Every release is built by GitHub Actions from a version tag in the public source repository, by the workflow release.yml. The build sends the programs to SignPath for signing; a release is signed only after a maintainer has approved that signing request. Nothing is built or signed on a personal computer. Each release lists the SHA-256 checksums of the zip and the plugin in SHA256SUMS.txt.

Team roles

  • Committers and reviewers: Ulrich Staudinger
  • Approvers: Ulrich Staudinger

Changes by other contributors come in as pull requests and are reviewed by a committer before they are merged. The main branch and the release tags are protected, and all team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

In detail: the app connects only to Resolume, at the address set in its settings (by default this computer, 127.0.0.1), and serves its user interface only to this computer. It has no telemetry and no update check. Links in the Help menu open in your browser when you click them. See also the privacy note.

Checking a download

Right-click seq-app.exe → Properties → Digital Signatures: a signed release shows "SignPath Foundation" as signer. Compare the zip's hash with SHA256SUMS.txt from the same release: Get-FileHash clip-sequencer-<version>-windows-x64.zip -Algorithm SHA256.

Questions or a suspected problem with a signed file: see the security policy.
